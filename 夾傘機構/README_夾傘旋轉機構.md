# 夾傘旋轉機構 3D 模型

## 檔案

- `夾傘旋轉機構_3D.blend`：Blender 主檔案
- `blender_generate_clamp_mechanism.py`：參數化重建腳本
- `夾傘旋轉機構_正視預覽.png`：正視圖
- `夾傘旋轉機構_立體預覽.png`：立體圖
- `定向滾輪_尺寸修正版_近照.png`：單顆定向輪特寫，可看清固定孔與沖壓側板
- `定向滾輪_尺寸檢查.json`：實際網格尺寸與穿孔檢查結果

## 建模假設（單位：mm）

原始正視圖沒有標示整體尺寸，因此以商品圖的定向輪尺寸當作比例基準。

- 方形骨架、背襯和軸承座已移除，保留懸空的兩顆定向輪及驅動輪。
- 上方定向輪固定片：長 27、寬 11.4；採用圖面 11.4 標註，表格的 11 視為取整。
- 固定孔：直徑 4，兩孔中心距 18；均為真實穿孔，位於固定片長度中心兩側各 9。孔保留外露，便於檢查；商品配套螺絲規格為 M4 x 16。
- 橘色尼龍輪：直徑 12，輪面寬 9。
- 安裝總高：13，指固定片安裝面至輪胎最外緣；定向輪在組裝時向中央旋轉 90 度，因此此尺寸沿機構 X 軸量測。
- 緊湊式雙側沖壓輪架、輪軸、鉚釘頭、固定片中央開口依照片重建。
- 未標示尺寸：鈑金厚度估為 0.8、固定片外角 R3、輪軸直徑 3；輪架輪廓與鉚釘細節依照片估形。
- 傘柄夾持直徑：10（只有 Empty 定位參考，沒有傘或傘柄實體）
- 驅動輪：直徑 76，寬 18，目前是基本圓柱
- 動畫：1–120 幀，驅動輪與上方兩輪已設定旋轉關鍵幀，依輪徑比設定相同名義輪面速度；屬運動示意。

## 快速調整

開啟 `blender_generate_clamp_mechanism.py`，修改檔案前段的參數，再用 Blender 的 Scripting 工作區執行即可重建。最常需調整的是 `SHAFT_DIAMETER`、`DRIVE_RADIUS`、`DRIVE_WIDTH` 與定向輪位置。

本版本保留原有的名義 10 mm 傘柄位置，兩顆定向輪中心到傘柄中心距均為 11 mm，形成相切的三點接觸。腳本會從套用修改器後的幾何檢查輪徑、輪寬、固定片長寬、總高，並以射線驗證兩個固定孔貫穿，通過後才保存 `.blend`。

這是根據正視圖建立的機構概念模型；若要製作實體，還需依實際傘柄直徑、夾持力、驅動輪材質與馬達扭力完成工程校核。
