# 三路分流・平順流道修正版立體PNG

本次只讀取「第一版.blend」，在記憶體暫存場景中建立渲染用幾何並輸出PNG，未儲存或修改原始3D模型，未輸出.blend或STL，也未執行CFD。

- 保留兩台鼓風機的現有位置與82×88mm矩形接口。
- 矩形直段之後分成三路，截面由圓角長矩形漸變為圓形，並配合支路走向旋轉截面；圓管內徑先採50mm。
- 每支圓管接一個小型集風罩：以150mm長的候選過渡段漸變展寬、變薄，接12mm薄流道直段、R28mm的90度彎道，再以原版約51.43mm的收縮噴嘴接到2mm狹縫。
- 每側三段約20cm弧長，維持原圓弧出風位置與中央50mm排除範圍。段間暫留6mm構造空間，接縫處的風速均勻性尚未確認。
- 左側漸變接頭上端在圖中向後偏移90mm，以配合機殼內走管。鼓風機未移動。
- 候選管線與實際機殼表面沒有相交；其他接頭、分流鼻端、模組接縫、密封、支架與製造公差仍待設計。這不是製造圖，也未驗證內部流場、風速或壓損。

三張PNG分別呈現單側立體配置、雙側機殼輪廓內配置與末端集風罩近照。圖中箭頭只是預定方向，非模擬流線。150mm過渡長度屬本次外觀配置候選值，尚未確認為最佳值。
